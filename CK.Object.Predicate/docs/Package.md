Configured object predicates: ObjectAsyncPredicateConfiguration and ObjectPredicateConfiguration create `Func<object,ValueTask<bool>>` and `Func<object,bool>` predicates from configuration, composed in "All", "Any" or "Single" groups.

See the [README](https://github.com/signature-opensource/CK-Object-Mixer/blob/stable/CK.Object.Predicate/README.md).
